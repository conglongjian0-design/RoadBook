# 第一版需求与边界

依据用户路书文档及本次讨论整理。

## 已确认的产品要求

- 简洁 MVP，微信小程序，先满足个人骑行使用，也容纳步行游玩和自驾旅行路线。
- 可以上传路线文件、在地图展示、导出供其他 App/设备使用。
- 可以通过起点 + 多个有序途经点 + 终点制作路线。
- 微信用户身份，每份路书有作者；路书公开时进入公共库，私密时仅自己可见。
- 不在小程序中做导航。
- 用户目前使用 iPhone 和高德，没有码表。
- **第一版必须有进入高德 App 的路径；是否完全沿原路书导航可后续优化。**
- 用户尚未注册小程序，确认使用腾讯云开发。

## 本次实施选择

- 原生小程序，腾讯微信云开发，Node.js 云函数。
- 先支持 GPX 导入/导出，其他格式后续根据真实设备适配。
- 手动规划调用高德 Web 服务，原始几何轨迹保存为 WGS84。
- 新建路书默认私密，由作者主动公开。
- 浏览不要求先填写资料，创建路书时要求登录。
- 不添加点赞、评论、付费、运动排名或连续 GPS 录制。
- 浏览器预览只为本地查看与交互验证，不能冒充微信小程序或已上线服务。

## 当前未完成的外部验收

- AppID 注册、云环境创建、真实微信身份联调。
- 高德 Key 配置与真实道路规划联调。
- iPhone 上从微信位置页进入高德、以及 Safari 备用路径验证。
- 微信审核和发布。

这些依赖账户配置或目标真机，不应标记为已完成。
