# 路书 UI 与功能路线图

本清单来自《路书小程序 UI 设计》的 4 个核心页面：发现、路书详情、行程中、我的。设计稿表达的是完整产品愿景；当前代码已经实现的功能继续保留，尚无数据和服务支撑的界面不以假数据冒充。

## 本次 UI 改造

- [x] 全局改为 `#121212` 深色骑行主题，品牌色统一为 `#1ED760`
- [x] 发现页采用大标题、搜索、分类胶囊、精选路线和深色地图卡片
- [x] 路线缩略图改为黑色地图纹理、荧光绿轨迹、起终点标记
- [x] 路书详情改为沉浸式地图、作者信息、路线指标、地点时间线和底部导航按钮
- [x] 我的页面增加真实数据统计：路书数、公开数、已创建路线总里程
- [x] 创建、资料与高德导航入口统一为同一套深色组件
- [x] 保留搜索、路线筛选、GPX 导入导出、公开/私密、分享、编辑删除和高德跳转

## 实现顺序建议

1. 收藏 + 封面图，让“发现”和详情页的信息真实完整。
2. 多日路书模型，让旅行、自驾和长途骑行都能使用。
3. 行程执行与轨迹记录，这是开发量和稳定性要求最高的一阶段。
4. 个人统计与离线能力，在形成真实行程数据后接入。
